# 운동 기록 (점진적 과부하 PWA)

아이폰 Safari에서 "홈 화면에 추가"해 쓰는 헬스장 운동 기록 앱입니다. 서버, 로그인, 외부 라이브러리 없이 동작하고, 기록은 폰 안(localStorage)에만 저장돼요.

## 사용법
1. **홈**: 크게 보이는 "오늘 추천" 그룹(A↔B 번갈아)을 누르면 운동이 시작돼요. 이번 주(월~일)에 A와 B를 모두 했으면 C 힌트가 떠요.
2. **운동 화면**: 추천 무게와 횟수가 미리 채워져 있어요. 무게 `−`/`+`는 사다리에서 한 단계씩 움직여요. 실제로 한 값으로 고친 뒤 **완료**를 누르세요.
   - 완료를 누른 세트만 기록되고, 누르는 순간 저장돼요. 앱을 닫아도 다시 열면 이어서 할 수 있어요.
   - 세트를 완료하면 휴식 타이머가 시작돼요(설정에서 시간 변경).
   - 1세트 무게를 바꾸면 아직 안 한 다음 세트들도 같은 무게로 바뀌어요.
3. **운동 종료**: 저장하면 요약(무게 올린 종목, 총 세트)이 나와요.
4. **기록**: 날짜별 목록(잘못된 기록은 삭제 가능), 종목별 무게 그래프.
5. **설정**: 휴식 시간, 종목 편집(이름, 세트, 횟수 범위, 사다리 종류, 시작 무게, 숨기기, 순서), 종목 추가.
6. **백업**: "백업 복사"로 글자(JSON)를 복사해 메모 앱 등에 보관하세요. 복원할 때는 그 글자를 붙여넣으면 돼요. 14일 넘게 백업하지 않으면 홈에 알림이 떠요.

## 추천 규칙 (js/progression.js)
- 기록 없음 → 시작 무게 × 최소 횟수 (시작 무게가 없으면 직접 입력 안내)
- 모든 세트 최대 횟수 달성 → 사다리 한 단계 올리고 최소 횟수부터
- 모두 최소 이상 → 같은 무게, 세트별 지난번 +1회
- 최소 미달 세트 있음 → 같은 무게. 같은 무게에서 2회 연속 미달이면 한 단계 낮춤
- 14일 이상 쉼 → 지난 무게에서 1단계, 28일 이상 → 2단계 낮춤
- 맨몸 종목 → 횟수만 다루고, 최대 횟수를 채우면 "다음 단계" 안내

## 설정 상수 위치
- **추천과 사다리 기준 숫자**: `js/progression.js` 맨 위의 `CONFIG` (사다리 간격, 공백 일수, 감량 기준, 기본 휴식 시간, 백업 알림 일수)
- **기본 종목 목록**: `js/defaults.js` (앱을 처음 열 때만 쓰여요. 이후에는 앱 설정 화면에서 고친 내용이 우선이에요)
- **캐시 버전**: `sw.js` 맨 위의 `CACHE_VERSION`

## 업데이트 방법
1. 파일을 고친다.
2. `sw.js`의 `CACHE_VERSION`을 올린다 (예: `'v1'` → `'v2'`). **이걸 안 하면 폰에 반영되지 않아요.**
3. PowerShell에서 아래 명령으로 올린다:
   ```powershell
   cd C:\dev\Workout\gym-tracker
   git add -A
   git commit -m "업데이트"
   git push
   ```
4. 1~2분 뒤 폰에서 앱을 열면 "새 버전이 있어요" 안내가 떠요. **업데이트**를 누르세요. 안내가 안 뜨면 앱을 완전히 닫았다가 다시 열어 보세요.
